This is a simple reactr web app that collects a list of gifts I create for a holiday or event. I will use it to share with my family and friends. 

##Requirements
- Only I should be able to add, remove, or edit item information. even if it's protected by just a simple password i set.
- Users should be able to "check items off" the list like if they purchased something and they do not have to login to do it. People should be able to check stuff off the list so others know not to buy an item.
- This should be easy to view and use on mobile and desktop
- Fun and engaging UI/UX to feel playful and fun to use.
- There should be a table view and then a card view with one item at a time, and people should be able to toggle between them. The default view should be the table view.
-In the table view and I guess in general for the items, you should have:
    - an item name
    - a link to Amazon
    - a link to another reputable retailer
    - the lowest estimated price
    - an automatically generated two-line description
    - a visual indicator of the item's status (checked off, not checked off, etc.)

##User Flows
As justin the list maker, I want to be able to edit the exisiting infotmation on the list.
As justin the list maker, I want to be able to add new items to the list, and include all necessary information.
As a gift giver, I want to be able to check items off the list so others know not to buy an item.
As a gift giver, I want to be able to see the list of items and the status of each item.
